# Техническое обслуживание бизнеса — tech.servgo.ru

Готовый адаптивный статический лендинг для поискового продвижения в Яндексе по запросам технического обслуживания бизнеса в Сочи. Создан на основе проверенной версии с исправленным QR и десктопной раскладкой.

## Публикация без влияния на ServGo
1. Используйте ветку `feat/tech-servgo-yandex-seo-20261009`.
2. Скопируйте **три файла** `sites/tech-servgo/index.html`, `robots.txt`, `sitemap.xml` в корень отдельного виртуального хоста `tech.servgo.ru`.
3. Создайте/проверьте DNS запись `tech.servgo.ru`, отдельный HTTPS виртуальный хост, редирект HTTP → HTTPS; основной сайт `servgo.ru` не менять.
4. Убедитесь, что URL `https://tech.servgo.ru/` возвращает 200, а `https://tech.servgo.ru/robots.txt` и `https://tech.servgo.ru/sitemap.xml` доступны без авторизации.
5. Верифицируйте поддомен в Яндекс Вебмастере. Установите регион Сочи при соответствии фактическому обслуживанию, отправьте sitemap.xml на сканирование. Пройдите ручную проверку отображения на мобильном устройстве.
6. Только после публикации установите реальный счетчик Яндекс Метрики и проверьте поисковые запросы/конверсии. ID счетчика и данные Wordstat не подставлялись без доступа.
