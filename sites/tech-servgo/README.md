# Техническая поддержка для бизнеса — tech.servgo.ru

Статический адаптивный лендинг, отдельный от действующего приложения ServGo.

## Публикация
1. Переключитесь на ветку `fix/tech-landing-qr-layout-20261009`.
2. Возьмите файл `sites/tech-servgo/index.html` и установите как `index.html` в корень сайта для `tech.servgo.ru`.
3. Настройте DNS и HTTPS для `tech.servgo.ru`. **Не** заменяйте существующий сайт `servgo.ru`.
4. После публикации проверьте QR на телефоне, кнопки Telegram, телефон и карточки тарифов.

Внешние ассеты, сборка, пакетный менеджер и серверное приложение **не нужны**. QR-код для контакта и vCard встроены прямо в HTML, поэтому отдельный файл PNG не потеряется при публикации.

Контакт в QR: «Техническое обслуживание Артур»; телефон `+7 996 030-65-93`; Telegram `https://t.me/Grunvald`.

## Проверенные состояния
- Desktop 1440, 1280, 1024, tablet 768, mobile 390, 320 px: нет пересечения текста с иконками, нет горизонтальной прокрутки.
- Встроенное изображение QR загружается в браузере и декодируется как vCard.
- Тарифы сохранены: 6990 ₽ — 2 выезда/5 ч; 9900 ₽ — 3 выезда/7,5 ч; 14990 ₽ — 5 выездов/14 ч.
- Работы входят в тариф в пределах лимитов, материалы оплачиваются отдельно.
- Условие срочного выезда до 2 ч сопровождается оговоркой о рабочем времени и зоне обслуживания.
